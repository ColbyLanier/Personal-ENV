#coding/algorithm 
worst case analysis - take maximum time (index to back of the array)
average case analysis - more difficult to prove but more representative of user exp
- often proved by benchmarking and observation
best case analysis - easy to prove but not super useful

Efficiency: and algorithm is efficient if it achieves better worst case performance than [[Brute-Force]], and satisfies [[Polynomial Time]]

exceptions (uncommon)
there are very slow O(2^50) programs
there are O(n^2) that are in use
