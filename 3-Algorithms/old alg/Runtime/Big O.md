#coding/algorithm 
O(g(n)) = {f(n) | there exist positive constants c and n0 such that $0 \leq f(n) \leq c*g(n)$ for all $n \geq n0$}

Something is O(n) if f(n) $\leq$ c\*g(n) for all n

note: always write that $n \in O(n^2)$, not that $n = O(n^2)$
